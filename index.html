About

ClassManager is a single-page app: index.html + styles.css + app.js. No build step, no dependencies — open index.html directly or host it on GitHub Pages.

The ✉️ Parent msg button on each student uses the keyless Pollinations text API to draft a progress message; if you're offline or the API is busy, it falls back to a built-in template. No API key needed.
